# MVPスコープ

## 目的

都市樹木台帳をCSVから読み込み、地図・一覧・個体詳細で確認し、i-Tree Eco向けの入力候補CSVを出力できる最小の流れを検証する。

## MVP 1（このPR）

- 日本語・英語の代表的な列名を自動対応
- 緯度・経度を持つ樹木を地図表示
- ID・樹種検索、健全度の色分け、個体詳細
- 未定義列を追加項目として保持・表示
- 樹種とDBHを持つデータをi-Tree入力候補CSVへ変換
- 取込エラー・注意の表示

## MVP 2

- Supabase/PostgreSQL/PostGISへの保存
- 樹木マスタと調査履歴の分離
- ログイン、組織、権限、写真
- 列対応を画面で編集・保存
- i-Tree計算結果の取込と評価値表示

## MVPに含めないもの

- i-Treeの科学モデルの再実装
- 国内単価による貨幣価値の自動算定
- 本格的な危険度診断・作業管理
- オフライン現地調査

## 完了条件

1. サンプルCSVが地図と一覧に表示される。
2. 日本語列名のCSVを読み込める。
3. 独自列が失われず個体詳細に表示される。
4. 必須値不正の行を除外し、理由を表示する。
5. 樹種・DBH不足を除外してi-Tree入力候補を出力する。
