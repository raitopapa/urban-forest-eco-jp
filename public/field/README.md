# 現地入力PWA

`/field/` で公開するスマホ・タブレット向け**全木点検（スクリーニング）**アプリです。

## 点検の位置づけ

区域内の対象木を全数確認し、維持管理処置が必要な木と、次工程の外観診断へ回す木を抽出します。このアプリで行う点検自体は外観診断ではありません。東京都「樹木点検」をベースに街区向け項目を追加し、必要に応じて同じ現地訪問でi-Tree Eco用データも取得します。

## 評価区分

- **炭素のみ評価**: DBH、樹高、枝枯れ率、CLEを入力
- **＋その他生態系サービス**: 上記に加え、生存部樹高、樹冠基部高、樹冠幅、樹冠欠損率を入力
- **i-Tree評価なし**: i-Tree専用項目を非表示にし、通常の樹木点検のみ実施

内部コードは既存互換のため `A / B / N` を使用します。

## 現在の機能

- IndexedDBへの完全オフライン保存
- 1本の樹木に複数写真を保存
- GPS取得
- 枝枯れ率は「約1〜5%」等で表示し、内部値は3, 8, 13…として保存
- Excel点検票へ貼り付けるCSV出力（炭素のみ / ＋その他生態系サービス）
- i-Tree評価なし用の点検CSV
- JSONバックアップ
- PWA / Service Worker

## 選択肢のメンテナンス

`index.html` 冒頭の定数で後から追加できます。

- `SURVEYORS`: 点検者名
- `SPECIES_PRIMARY`: 基本樹種候補
- `SPECIES_ADDITIONAL`: 追加の高木性樹種候補

樹種候補にない場合は「その他（自由入力）」で記録できます。

## 保存先

入力データと写真は端末内のIndexedDBに保存されます。書き出し画面で、登録済み利用者がログインして「この端末の記録を送る」を押すと、写真本体を除く点検記録を開発用Supabaseへ送ります。PCから同じ画面でログインすると共有記録を閲覧・JSON保存できます。同じ内容の再送は重複せず、編集した内容は履歴として追加されます。自動送信や端末への自動取得は未実装です。

写真は記録を保存した後、編集画面の「写真を保存」で写真No.と写真IDを含む名前で取り出します。DB側には写真No.と対応ファイル名を保存します。Dropboxなどに写真を保管する場合は名前を変えずに置いてください。別端末に写真本体は転送されません。

Supabaseプロジェクト `urban-forest-eco-jp-dev` の `survey_records` / `survey_members` を使用します。担当者は Supabase Auth にメールアドレスとパスワードで登録し、その user ID を `survey_members` に追加してください。利用者未登録では送信できません。公開アプリに置くキーは publishable key のみで、service role key は使いません。ログイン情報はメモリ内のみ保持し、再読み込み後はログインし直します。共有DBの利用開始前に、現場データの投入先と利用者の権限を管理者が確認してください。
