# 現地入力PWA

`/field/` で公開するスマホ・タブレット向け樹木点検アプリです。

## 評価区分

- **炭素のみ評価**: DBH、樹高、枝枯れ率、CLEを入力
- **＋その他生態系サービス**: 上記に加え、生存部樹高、樹冠基部高、樹冠幅、樹冠欠損率を入力
- **i-Tree評価なし**: i-Tree専用項目を非表示にし、通常の樹木点検のみ実施

内部コードは既存互換のため `A / B / N` を使用します。

## 現在の機能

- IndexedDBへの完全オフライン保存
- 1本の樹木に複数写真を保存
- GPS取得
- 枝枯れ率は「約1〜5%」等で表示し、内部値は3, 8, 13…として保存
- Excel点検票へ貼り付けるCSV出力（炭素のみ / ＋その他生態系サービス）
- i-Tree評価なし用の点検CSV
- JSONバックアップ
- PWA / Service Worker

## 選択肢のメンテナンス

`index.html` 冒頭の定数で後から追加できます。

- `SURVEYORS`: 点検者名
- `SPECIES_PRIMARY`: 基本樹種候補
- `SPECIES_ADDITIONAL`: 追加の高木性樹種候補

樹種候補にない場合は「その他（自由入力）」で記録できます。

## 保存先

現時点では入力データと写真は端末内のIndexedDBが正本です。
オンライン復帰時のSupabase自動同期は次段階で実装します。
