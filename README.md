# Urban Forest Eco JP

都市樹木の台帳、地図表示、データ変換、i-Tree Eco連携を行うオープンな基盤を目指すプロジェクトです。

このリポジトリでは、i-Treeの科学モデル自体は再実装しません。国内の街路樹・公園樹管理項目を保持しながら、i-Treeへ渡すデータと計算結果を追跡・可視化します。

## 現在のMVP

- CSVから樹木台帳を読み込む
- 地図、一覧、個体詳細を表示する
- 日本語・英語の代表的な列名を内部項目へ対応付ける
- 独自列を追加項目として保持する
- i-Tree Eco向け入力候補CSVを出力する

## Webアプリ

- [管理・可視化画面](https://raitopapa.github.io/urban-forest-eco-jp/)
- [現地入力PWA（全木点検）](https://raitopapa.github.io/urban-forest-eco-jp/field/)
- 現地入力はIndexedDBへ保存し、オフラインでも利用可能
- 登録済み利用者は現地入力画面の「書き出し」から、写真本体を除く点検記録を共有DBに手動送信できます。写真No.とファイル名を紐付けます。詳しくは[現地入力PWAの手順](public/field/README.md)を参照してください。
- 管理画面では同じ登録済みアカウントでログインすると、共有DBの点検記録を地図・台帳・集計に読み込みます。編集履歴は木ごとに最新の記録を表示します。「共有記録を再読込」で追加分を反映できます。
- 管理画面のログイン状態はブラウザのメモリ内に保持します。再読み込み後はログインし直してください。
- ログイン前の5本は架空のサンプルです。共有データ閲覧中は「表示中: 共有記録」と示します。CSVの手動読込やサンプル表示にも切り替えられます。ログアウトするとサンプルに戻ります。
- DBHや樹高が未記入の木も地図・台帳に表示します。写真本体は共有DBに保存しないため、管理画面では写真No.とファイル名だけ確認できます。
- 共有記録を表示中は「i-Tree Eco取込用Excelを出力」から、最新の送信記録の調査値を `.xlsx` で保存できます。「i-Tree評価なし」の木は対象外です。評価対象の木に樹種コード・DBH・一意な樹木番号がそろわない場合は、対象木と理由を表示して出力を止めます。
- Eco用Excelは **全木調査（Complete Inventory）** のインポート用です。i-Tree Ecoの「Data → Trees → Import」でファイルを選び、列とEcoフィールドの対応、樹種コード、取込件数を確認します。Webアプリからi-Treeへの自動投入やモデル計算は行いません。
- DBHはcmからinch、樹高・樹冠などはmからfeetへ換算します。株立ちのDBH1〜6を別列で保持します。和名が自動対応しない場合は、i-Tree Ecoの樹種コードを画面で登録します。使用するコード一覧は[公式の樹種一覧（2023年）](https://www.itreetools.org/documents/864/i-Tree_Eco_species_list_1.17.2023.csv)を元にしています。最新のコードはi-Tree Ecoの「View → Species List」で確認してください。
- 土地利用はi-Treeプロジェクト設定ごとに値が変わるため自動変換しません。株立ちの複数DBHの列はEcoの取込ウィザードで個別に対応付け、試験取込で反映を確認してください。現状のi-Tree Ecoデスクトップでの実取込は未検証です。
- 自動同期は次段階で実装予定
